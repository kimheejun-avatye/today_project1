# 고민과 설계 과정 원본

이곳은 현재 구현 설명서가 아니라, 질문·대안 비교·결정 변경 과정을 보존한 기록이다. 정리 전 ZIP에서 아래 다섯 문서를 내용 변경 없이 복원했다. 옛 파일의 상대 링크와 당시 미확정 내용도 원문 그대로이므로 현재 구현 여부는 [현행 설계 결정](../decisions.md), [인증 정책](../authentication.md), [DB 설계](../database.md)에서 확인한다.

| 원본 | 보존한 내용 |
|---|---|
| [내가 고민했던 점](내가%20고민했던%20점.md) | 무엇을 질문했는지, 선택 이유, 바로잡은 오해와 남은 질문 |
| [회원가입·로그인 설계 계획서](회원가입-설계-계획서.md) | 초기 대안, 후속 합의, 토큰·글 보존·데이터 관계 설계 과정 |
| [초기 최종 회원가입 계획서](최종%20회원가입%20계획서.md) | 가입 정책과 행 잠금 선택의 비교·근거 |
| [후속 전체 설계 계획서](project1/전체%20설계%20계획서.md) | API·시스템 구성과 JWT·서버 로그인 기록 병행 판단 |
| [후속 최종 회원가입 계획서](project1/최종%20회원가입%20계획서.md) | 구현 진행에 따라 구체화한 가입·캡차·동시 처리 결정 |

두 회원가입 계획서는 같은 이름이지만 작성 단계와 내용이 달라 둘 다 보존했다. 과거 문서의 완료·미완료 표현은 당시 상태다. 문서 정리 시 이 기록을 중복 설명이라는 이유만으로 삭제하거나 요약본으로 대체하지 않는다.
